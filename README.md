# expo-floating-bubble-overlay

Floating chat-head bubble for Android that draws over other apps and brings your Expo app back to the foreground.

> **Work in progress.** The API is not published yet.

- **Android only.** iOS does not allow drawing over other apps; on iOS, web and Expo Go the module is a safe no-op.
- Built with the Expo Modules API (Kotlin).
- Originally developed inside the Run Pilot driver app and extracted as a standalone package.
